# Attribute Management Database

## Overview

This project is a SQL Server database developed for the Amicus Fresher Development Program – Path 2.

The database supports an Attribute Management System and demonstrates relational database design, data integrity, stored procedures, user-defined functions, indexing, and SQL Server programming concepts.

---

## Database Features

- Database: TrainingDB
- Schema: shashank
- Normalized relational design
- Primary, Foreign, Unique, Check and Default constraints
- Seed data for testing
- Stored Procedures for CRUD and reporting
- Scalar and Table-Valued Functions
- Nonclustered and Covering Indexes
- Audit table and triggers
- Error handling using TRY...CATCH
- Transaction handling with XACT_ABORT
- Dynamic SQL with validation
